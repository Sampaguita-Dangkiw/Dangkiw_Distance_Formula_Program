# Distance Formula Program

   This program will be used to calculate the distance between two coordinates.
Where (x1,y1) will be the first coordinate and (x2,y2) will be the second coordinate.


### How to use the code:

- Open the file on PyCharm
- Run the program
- enter the input needed
- get the displayed output

### Input Needed

- `x1`
- `y1`
- `x2`
- `y2`

### Processing stage

- The distance formula is the square root of (x2 - x1)^2 - (y2-y1)^2. I implemented this formula in PyCharm using the following processes:

`result` = (pow (`x2` - `x1`, 2)) + (pow (`y2` - `y1`, 2))

`distance` = math.sqrt(result)

### Output Stage

- It will display the distance using (print(f"The distance is {distance:.2f}")

### Sample Output

**Input**
- x1 = 10
- y1 = 12
- x2 = 15
- y2 = 13

**Output**
- The distance is 5.10
